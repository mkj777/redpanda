# redpanda

A minimal desktop mail client for Windows. Gmail, Outlook/Microsoft 365 and any IMAP/SMTP mailbox in one window, built with Tauri and Rust.

> Status: work in progress. See the [roadmap](docs/PLAN.md).

## Features (planned for v1)

- Gmail and Outlook sign-in with OAuth in your browser, password or app password for everything else
- Server settings detected from your email address
- Unified inbox across all accounts
- Three resizable columns: folders, message list, reading pane
- Remote images blocked by default
- Plain-text compose, reply, reply all, forward
- English and German UI
